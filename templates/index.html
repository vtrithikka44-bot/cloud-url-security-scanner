System Architecture Note: This application is implemented as a lightweight, stateless web service ready for cloud application hosting (PaaS platforms such as Render, Railway, or AWS Elastic Beanstalk). All URL heuristics are performed locally in-memory using Python's urllib.parse and regex matching. No external requests are sent to target hosts, preventing remote code execution, server side request forgery (SSRF), and outbound reconnaissance risks.
